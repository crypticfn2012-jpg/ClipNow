RON ClipTools captures real 1080p60 clips on BuildNow.GG. Install the userscript, clip in-game, then upload here.

Download RON ClipTools Get Violentmonkey
1. Install Violentmonkey Chrome, Edge, Firefox, or any Chromium browser. Tampermonkey also works.
2. Install the script Click Download RON ClipTools. Violentmonkey should offer to install it. If it only downloads a file, open Violentmonkey → New → paste the file contents → Save.
3. Open BuildNow.GG Play on buildnow.gg or CrazyGames. The ClipTools panel appears on the game canvas.
4. Clip, then upload Press F9 for a 15s clip, F8 for a screenshot, F7 to toggle the panel. Then come back and upload the file.
